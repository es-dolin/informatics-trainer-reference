# ИнфоЛаб - интерактивная лаборатория информатики

Демонстрационное статическое веб-приложение для учеников 8–9 классов. ИнфоЛаб помогает разбирать темы информатики, решать интерактивные задания и понимать ход решения.

Это учебный ориентир, а не код самостоятельной работы Егора. Задания создаются программой и не являются копиями вариантов ВПР.

## Запуск

Нужен Node.js 18 или новее. Сборка и установка пакетов не требуются.

1. Открой папку проекта в VS Code.
2. Открой встроенный терминал в папке проекта.
3. Запусти локальный сервер:

   ```sh
   npm run dev
   ```

4. Открой адрес, который покажет терминал (по умолчанию `http://localhost:4173`).
5. Чтобы остановить сервер, нажми `Ctrl+C` в терминале.

Страницу нужно открывать через этот сервер, потому что приложение использует нативные ES-модули браузера.

## Что реализовано

- Пять модулей: системы счисления, арифметика, математическая логика, алгоритмы и исполнители, анализ программ.
- Во всех пяти темах работают два режима: «Изучай и тренируйся» с проверкой каждого шага и «Проверь себя» с самостоятельным решением и разбором после ответа.
- В «Изучай и тренируйся» слева находятся поля текущего шага, справа - краткая инструкция и нужное правило. Кнопка «Ещё пример» создаёт другое задание на тот же приём.
- Список «Вид задания» позволяет выбрать конкретный приём. Для перевода чисел исходная и новая системы выбираются отдельно; одинаковые основания недоступны. При смене незавершённой задачи приложение спрашивает подтверждение.
- «Проверь себя» предлагает новую задачу того же подтипа и сравнимой сложности. В арифметике сохраняются операция и основание, в переводах - исходное и целевое основания. До ответа план и подсказки скрыты.
- После непустого ответа кнопка «Решить по шагам» открывает эту же задачу в «Изучай и тренируйся», а «Показать готовое решение» раскрывает текст решения. Результат самостоятельной попытки сохраняется. Следующий переход к самопроверке даёт новую аналогичную задачу.
- Пошаговые маршруты охватывают переводы и сравнение чисел; переносы, займы, частичные произведения и деление; логические операции по строкам; обратный путь числового исполнителя; координаты после каждого смещения; условия и итерации программы. При переводе в десятичную систему разбирается значение каждого разряда.
- Сложение, вычитание и двоичное умножение показываются столбиком. Первая строка таблицы истинности и первый запуск программы с условием разбираются подробно, остальные предлагается выполнить более самостоятельно.
- В числовом исполнителе ученик выбирает возможную последнюю команду и строит обратный путь. В разборе Чертёжника путь строится после проверки координат; сетка с осями и одинаковым масштабом сохраняется на всех шагах задачи. В программах выделяется текущая строка. Пустой или неверный промежуточный ответ не продвигает маршрут.
- Генерация новых задач, проверка ответов, обратная связь и пошаговые решения.
- Сравнение чисел включает все три ответа: `<`, `=` и `>`; записи сравниваются по числовым значениям.
- Переключение режима сохраняет учебный шаг и черновик самостоятельного ответа. Новая задача явно начинает новую попытку.
- В результатах учитывается только первый непустой итоговый ответ в «Проверь себя». Ошибки и исправления учебных шагов, повторная проверка и пустой ответ не добавляют попытки. Прежние сохранённые счётчики остаются доступными.
- Очистка результатов требует подтверждения.
- Сравнение чисел в основаниях 2, 8 и 16; перевод между основаниями 2, 8, 10 и 16.
- Сложение и вычитание в основаниях 8 и 16; четыре арифметические операции в двоичной системе.
- Логические выражения и таблицы истинности на двух и трёх переменных.
- Числовой исполнитель и визуальный «Чертёжник» на координатной сетке.
- Пошаговая симуляция заранее заданных программ с условием и циклом. Произвольный пользовательский код не исполняется.
- Экран результатов, счётчики попыток и верных ответов в `localStorage`.
- Адаптивная раскладка, управление с клавиатуры, видимый фокус и настройка уменьшения анимации.

## Покрытие ВПР

Матрица сопоставляет отдельные учебные упражнения с навыками заданий № 1–10 описания ВПР-2027. Генерация и проверка реализованных подтипов покрыты автоматическими тестами. Это не полное покрытие всех вариантов ВПР и не имитация проверочной работы: используются новые примеры, а задания № 11 и 12 не входят в проект. Границы соответствия указаны в [docs/VPR_MAPPING.md](docs/VPR_MAPPING.md).

## Тесты

Запусти автоматические тесты чистых функций:

```sh
npm test
```

Используется встроенный тестовый модуль Node.js `node:test`. Тесты проверяют вычисления, граничные случаи, все знаки сравнения, учёт первой попытки, пошаговый перевод и пользовательские сценарии пяти модулей. Результаты и границы проверки записаны в [docs/TEST_PLAN.md](docs/TEST_PLAN.md).

Для проверки отрисованного интерфейса сначала запусти сервер, затем в другом терминале:

```sh
npm run test:browser
```

Эта дополнительная команда требует Node.js 22+ и установленный Edge или Chrome. В Windows путь определяется автоматически; для другой установки задай `INFO_LAB_BROWSER`. `INFO_LAB_URL` меняет адрес сервера (по умолчанию `http://localhost:4173/`). Проверка создаёт отдельный профиль браузера и скриншоты в игнорируемой папке `artifacts/browser`, проходит все темы и режимы, проверяет Tab/Enter и ширины 320, 390, 768 и 1440 px. Пользовательский профиль не используется.

## Ограничения

- Модуль двоичного деления создаёт только примеры с целым частным.
- «Чертёжник» строит короткую последовательность координатных смещений. Полноценный язык «КуМир» в проекте не создаётся.
- Анализ программ ограничен несколькими фиксированными шаблонами условия и цикла. Интерпретатора Python нет.
- Результаты хранятся только в браузере на текущем устройстве. При очистке данных сайта прогресс исчезнет.
- Исполнитель «Черепаха» и задания «Робот» № 11 и 12 исключены из объёма.
- Проект предназначен для демонстрации и обучения; он не заменяет официальные материалы или проверочную работу.

## Публикация на GitHub Pages

Удалённый репозиторий и публикация не выполнялись. Для последующей публикации владелец может создать репозиторий `es-dolin/informatics-trainer-reference`, отправить содержимое ветки `main`, затем в настройках репозитория открыть **Settings → Pages** и выбрать публикацию из ветки `main`, каталог `/ (root)`. Сборка не нужна. Ссылки приложения относительные, поэтому главная страница должна открываться и по адресу GitHub Pages для подпапки репозитория.
