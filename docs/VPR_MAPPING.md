# Соответствие демонстрационного тренажёра ВПР-2027

Документ сопоставляет учебные упражнения с заданиями № 1–10 образца ВПР по информатике для 8 класса. Источники содержат документы с пометкой © 2027 Федеральной службы по надзору в сфере образования и науки. Это карта навыков, а не копирование варианта ВПР.

Проверены разделы описания «Распределение заданий проверочной работы по позициям кодификатора» и «Типы заданий, сценарии выполнения заданий», а также задания части 1 в образце. Приведённые ниже номера взяты из официального распределения в описании; это важно, поскольку текстовая расшифровка на странице-копии образца отображает номера непоследовательно.

## Границы соответствия

- На этапе планирования ничего из матрицы не считается реализованным или проверенным.
- Сопоставление относится к навыкам, заявленным для заданий № 1–10. Оно не означает воспроизведение официальных заданий или полное соответствие всей проверочной работе.
- Задания № 11 и № 12, включая исполнителя «Черепаха» и «Робот», в демонстрационный проект не включаются.
- В модуле арифметики двоичное деление будет строиться так, чтобы ответ был целым. Это безопасный учебный подтип, а не заявление об охвате всех возможных формулировок.
- Статус строки будет изменён на «реализовано» только после появления работающего упражнения и на «проверено» только после успешного автоматического тестирования соответствующей логики.
