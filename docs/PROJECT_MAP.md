# Карта проекта

## Папки и файлы

| Путь | Назначение |
|---|---|
| `index.html` | Начальная HTML-страница, подключает стили и точку входа JavaScript. |
| `css/styles.css` | Цвета, сетки, карточки, состояния заданий, адаптивная раскладка и анимации. |
| `js/app.js` | Переключает экраны и режимы, строит форму текущего задания, принимает ответ и показывает обратную связь. |
| `js/storage.js` | Читает и сохраняет обезличенные счётчики в `localStorage`; переживает повреждённую запись. |
| `js/modules/index.js` | Список пяти модулей и их связь с общими экранами. |
| `js/modules/systems.js` | Перевод чисел, сравнение записей и задачи по системам счисления. |
| `js/modules/arithmetic.js` | Арифметика в основаниях 2, 8 и 16. |
| `js/modules/logic.js` | Дерево логического выражения, вычисление и построение таблиц истинности. |
| `js/modules/executors.js` | Числовой исполнитель и координатный «Чертёжник». |
| `js/modules/programs.js` | Фиксированные шаблоны программ и их безопасная пошаговая симуляция. |
| `tools/dev-server.js` | Маленький локальный HTTP-сервер на стандартном модуле Node.js. |
| `tests/` | Автоматические тесты чистой логики и генераторов. |
| `docs/` | Матрица ВПР, карта, объяснения кода, мост Python–JavaScript и тест-план. |
| `package.json` | Команды `npm run dev` и `npm test`; внешних зависимостей нет. |

## Как проходит ответ

1. `app.js` выбирает объект модуля из `modules/index.js`.
2. Функция `generateTask()` модуля создаёт объект задания: формулировку, вид поля ответа, правильный результат, подсказку и шаги решения.
3. `app.js` отображает поля по типу (`text`, `choice`, `multi-choice` или `truth-table`).
4. После отправки приложение передаёт объект задания и ответ в `checkAnswer()` этого же модуля.
5. Чистая функция возвращает результат проверки и понятное сообщение; приложение показывает обратную связь и шаги решения.
6. `recordAttempt()` обновляет локальные счётчики, а экран прогресса читает их обратно через `loadProgress()`.

Математические функции не знают о HTML. Поэтому их можно проверять Node.js тестами и повторно использовать при развитии интерфейса.
